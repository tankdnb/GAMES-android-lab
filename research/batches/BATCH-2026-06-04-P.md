## Working Notes

- Main question for this batch was whether `hm-defense` was still substantial enough to keep in the main catalog despite slower recent code activity, or whether it should stay only as a narrow `reference-only` Android gameplay sample.
- Final verdict: `reference-only`.
- Why:
  - the repository still offers a few worthwhile ideas around Scene2D HUD composition, a scrollable battlefield with radar mirroring, JSON-driven build and upgrade tables, and a tiny deferred z-sorted batcher
  - the checked-in runtime is clearly unfinished, the README's Android target is not actually present in the module graph, and no meaningful automated tests were found
  - it is better preserved as a compact libGDX comparison sample than promoted as a current Android game baseline
- Main reusable seams confirmed during the pass:
  - `AbstractScreen.kt`, `StageScreen.kt`, and `UIWorld.kt`
  - `Batcher.kt`
  - `Radar.kt`
  - `GameSave.kt` plus `build-info.json` / `upgrades.json`
  - `core` / `desktop` build split with successful `gradlew help` discovery
