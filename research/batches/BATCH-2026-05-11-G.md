## Working Notes

- The batch confirmed that `fredboy/cavedroid` is worth keeping as a main `android-game` catalog entry rather than as a niche comparison note.
- Its strongest reusable ideas are seam-safe wrapped-world handling across rendering and physics, chunk-local block/collider invalidation, layered procedural world generation, a hybrid RLE+ProtoBuf save pipeline, and touch-first sandbox controls with explicit walk/cursor mode switching.
- Local Gradle discovery reached a clear environment boundary: `cmd /c gradlew.bat --version` works, but `cmd /c gradlew.bat help --no-daemon` fails because the inspected Gradle `9.0.0` / Java toolchain requires JVM `17+`, while this lab machine still exposes Java `8`.
- Upstream `README.md` also warns that Windows desktop builds need asset-symlink tweaks, so even with a newer JDK the repository should still be treated as a static-first research target unless a narrower build verification step is specifically needed.
