## Working Notes

- Main question for this batch: whether `Dooz` is only a narrow polished Compose sample or still contains enough reusable Android game-product patterns to justify catalog inclusion despite its small tic-tac-toe scope.
- Expected hotspots before cloning: `app`, game state and controller flow, AI or opponent logic if present, board rendering/input handling, persistence/settings, screenshot/publishing surface, and any test coverage.
- Final verdict: `accepted`
- The decisive factors were the direct Android/Compose focus, DataStore-backed settings shell, heuristic AI, and especially the explicit RTL/Persian UI handling inside a real shipped board-game surface.
- The main caveats are the repository's narrow scope, complete lack of tests, GPL-3.0 licensing, and the fact that local Gradle discovery in the lab currently stops at the Java `17` floor while one fastlane metadata file still advertises an outdated `9x9` board limit.
