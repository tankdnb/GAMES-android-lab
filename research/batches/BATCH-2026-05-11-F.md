## Working Notes

- The batch confirmed that `DinoCompose` is worth preserving only as a `reference-only` catalog entry.
- Its most reusable ideas are path-based Compose vector rendering, tiny endless-runner state holders, and runtime hitbox-debug toggles.
- The repository was not promoted as a primary Android model because it mutates gameplay state during composition, still relies on global mutable dimensions plus `LiveData`, has only placeholder tests, and sits on an older Compose/AGP toolchain.
- Local Gradle discovery is blocked in this lab by the current Java `8` runtime, while the inspected repository requires Java `11+` even for lightweight `gradlew help` evaluation.
