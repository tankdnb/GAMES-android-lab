## Working Notes

- Main question for this batch: whether `glare` is a real reusable engine reference or only a thin low-signal LWJGL experiment.
- Expected hotspots before cloning: core loop, renderer abstraction, scene/entity structure, asset/shader flow, input handling, tests, and build discipline.
- Final verdict: `reference-only`
- Main reasons:
  - the repository still has some compact reusable ideas around node/component dependency wiring, editor-in-runtime tooling, split engine/editor packaging, and a readable fixed-step loop
  - the inspected runtime is not mature enough for a main catalog baseline because physics is effectively disabled, render traversal only walks root children, the README is partially stale, and the visible test surface is mostly a demo harness
- Main caveats:
  - direct Android transfer is only indirect, and any serious revisit should happen in a JDK `22` environment with a narrowly scoped question instead of a broad full-repo rerun
