# Context Index

Start here when resuming work in this repository.

## Read Order

Assume `AGENTS.md` has already routed you here. Then read:

1. `docs/context/PROJECT_BRIEF.md`
2. `docs/context/OPEN_TASKS.md`
3. `docs/context/HANDOFF.md`
4. `docs/context/DECISIONS.md`
5. `research/RESEARCH_PLAN.md` if the task involves GitHub scouting or repository analysis
6. Latest note in `docs/context/sessions/` if additional local context is needed

## Canonical Memory Files

- `docs/context/PROJECT_BRIEF.md`: stable summary of project purpose, scope, and current verified state
- `docs/context/HANDOFF.md`: latest high-signal handoff for the next session
- `docs/context/OPEN_TASKS.md`: active queue and recommended next steps
- `docs/context/DECISIONS.md`: durable process and repository decisions
- `docs/context/sessions/SESSION_TEMPLATE.md`: template for short session notes
- `research/RESEARCH_PLAN.md`: canonical runbook for scouting and studying external repositories

## Compatibility Notes

- `docs/context/project-overview.md` is a legacy alias retained for compatibility with older references.
- Public-facing overview remains in `README.md`.
- Catalog work lives under `catalog/`, with `catalog/index.md` as the quick scan entry point.

## Update Rules

- After each meaningful session, update `HANDOFF.md`.
- When priorities change, update `OPEN_TASKS.md`.
- When a durable repository or workflow decision is made, update `DECISIONS.md`.
- Add a short session note only when it preserves local context that will help future work.
- Keep memory distilled and verified against repository state.
