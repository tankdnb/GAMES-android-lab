# Catalog Projects

Store normalized per-project catalog cards here after a repository has been researched and judged worth keeping in the library.

Recommended file name format:

- `owner-repo.md`

Each card should be based on `catalog/templates/project-entry-template.md` and should link back to the detailed research note in `research/findings/`.

Use `catalog/CATEGORY_SCHEMA.md` for the primary category and focus tags, then add links to accepted cards in `catalog/CATEGORY_INDEX.md`.
